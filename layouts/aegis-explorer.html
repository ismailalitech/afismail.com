Fleet replay

Not live. These are verdict lines from the gateway's journal, recorded on the bench and kept in the repository's evidence/ files. Each step replays one line and updates that device's row.

State of each device after the current line
DeviceKindTrustLast verdictHeartbeatStackttl

Columns: Kind is the endpoint's kind in the gateway's policy. Trust is the label the gateway prints with the verdict; it prints one only for the kinds whose quote is a plain claims map, so an STM32 line (kind aegis-pq) has none. Heartbeat is the counter of the current session, Stack the secure partition's stack high-water mark (sstack= on the STM32, stack= on the RW612) and ttl the seconds the session has left on the endpoint's own clock, each as the last heartbeat reported it.
